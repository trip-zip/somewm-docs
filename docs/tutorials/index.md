# Tutorials

Each tutorial builds one piece of a desktop on a running SomeWM session and leaves you with something you can see. Follow them in order; each uses what the one before made.

| Tutorial | You end with |
| --- | --- |
| [Try SomeWM without logging out](try-somewm-without-installing.md) | SomeWM running in a window on your current desktop |
| [Learn the basics](basics.md) | Windows tiled, tags switched, your terminal in the config |
| [Build a clock widget](widgets.md) | A clock module with hover and click, in a box on screen |
| [Build a bar](wibar.md) | A bar with tags, tasks, the tray and your clock |
| [Add keybindings](keybindings.md) | Your own shortcuts, including media keys |
| [Make a theme](theme.md) | Your colors, fonts and borders in a theme file |
| [Try the carousel layout](carousel.md) | Columns that scroll instead of shrinking |

For a single task with a known answer, use the [how-to guides](../guides/index.md). For the full list of what a class can do, use the [reference](../reference/index.md).
