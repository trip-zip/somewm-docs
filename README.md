# somewm-docs

Documentation for [somewm](https://github.com/trip-zip/somewm), a Wayland compositor with an AwesomeWM-compatible Lua API. Lives at [somewm.org](https://somewm.org).

The docs aim to be *self-sufficient* — a complete reference for SomeWM users — so you don't need to bounce between sites. Organized via the [Diátaxis framework](https://diataxis.fr/) for clearer separation of tutorials, how-to guides, reference, and concepts. See [`docs/intro.md`](docs/intro.md) for what these docs aim to be (rendered at [somewm.org/docs/intro](https://somewm.org/docs/intro)).
